# Data sources

Every source, what it contains, and what will mislead you if you ignore it.

`opendxb sources` prints this table with local ingest status attached.

---

## Verifying endpoints before you trust an ingest

Dubai Pulse reorganises dataset paths without notice. The resource URLs compiled into this package are the best known at time of writing and are **not a contract**.

Before a first real ingest:

1. Sign in at [dubaipulse.gov.ae](https://www.dubaipulse.gov.ae) and find the dataset.
2. Copy the current CSV resource URL.
3. Override it for the run:

```bash
export OPENDXB_ENDPOINT_DLD_TRANSACTIONS="https://www.dubaipulse.gov.ae/.../current.csv"
opendxb ingest dld.transactions
```

The variable name is the source id uppercased with `.` and `-` replaced by `_`.

If an ingest returns far fewer rows than expected, or a high unresolved-location count, suspect the endpoint before suspecting the parser.

## `dld.transactions` — DLD · auth required

Every property sale, mortgage and gift registered with Dubai Land Department.

**Caveats.**
- DLD publishes full history in one export rather than a delta feed. A first ingest is large and slow, and this is why token refresh matters.
- Amounts are the **registered consideration**, not always the economic price. Related-party transfers, portfolio deals and bulk developer sales appear at values that will distort a naive average — a further reason the profile reports medians.
- Off-plan classification is derived from the registration-type column and is `null` where that column is absent.

## `dld.rents` — DLD · auth required

Registered residential and commercial tenancy contracts (Ejari).

**Caveats.**
- Registration is the landlord's obligation and compliance is imperfect. The contract set **understates the low end of the rental market**, so a community median skews high relative to what tenants actually pay.
- Rents are as registered, excluding agency fees, security deposits, DEWA and the chilled-water charges that materially change a tenant's real cost.
- A renewal and a new contract for the same unit both appear; there is no deduplication by property.

## `khda.schools` — KHDA · open

Dubai private schools with inspection rating, curriculum, enrolment and fee band.

**Caveats.**
- Schools are not all inspected in the same cycle, so two ratings are **not necessarily contemporaneous**.
- Fee bands are approved maxima, not what a given family pays after sibling discounts, scholarships or mid-year joining.
- Public schools are outside KHDA's private-school register and therefore absent.

## `dha.facilities` — DHA · open

Hospitals, clinics, pharmacies and diagnostic centres licensed by Dubai Health Authority.

**Caveats.**
- A licence record says a facility is **permitted to operate** — not that it is open, accepting patients, or in any given insurance network.
- Facility counts per community measure supply, not access or quality.

## `rta.stations` — RTA · open

Metro, tram, bus and ferry stations.

**Caveats.**
- A station being inside a community's boundary is not the same as being *walkable* from it — which in Dubai, for much of the year, is the question that actually matters.

## Licensing

Dubai open data is published by its respective authorities under the Dubai Open Data Licence (Dubai Data Law No. 26 of 2015). This package is MIT-licensed **tooling**; it does not redistribute Dubai's data. You are responsible for complying with each authority's terms for data you ingest.

## The bundled sample is not data

`data/samples/*.json` is synthetic, generated by `scripts/generate-sample.mjs` from a seeded PRNG. Every record carries `synthetic: true`, `SampleStore` refuses writes, the CLI prints a warning, and the MCP server tags every sample-backed response. It exists so the tooling is explorable without credentials. **Never quote it as a Dubai figure.**
